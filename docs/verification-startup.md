# 로그인 자동 실행 및 기능 복원 검증

WindowBridge 0.2.2, 2026-10-21.

- 사용자 토글의 성공한 켜기/명시적 끄기 저장, 복원 실패 시 저장값 보존, 두 기능의 독립 복원 테스트 통과.
- 기존 설정/복구·한영 보호·창 전환·창 관리 회귀 검사 통과.
- release 빌드와 코드 서명 검증 통과. 설치 앱과 배포 빌드 바이너리 일치.
- 실제 설치 앱에서 SMAppService 로그인 항목 등록 → 켜짐 확인 → 해제 → 꺼짐 확인 → 재등록 → 켜짐 확인.
- 재빌드 후 같은 설치 위치에서 로그인 등록 상태 유지 확인.
- 실제 설정 UI의 새 항목 표시와 하단 잘림 없음 확인.
- 기존 권한 재연결 후 Alt+Tab과 창 관리를 켜고 앱 정상 종료/재실행. 두 체크박스 켜짐과 복원 성공 메시지, 두 저장값 유지 확인.
- 시스템 설정의 로그인 목록에 WindowBridge 등록 확인. 충돌하는 BetterCmdTab 로그인 항목은 해제.
- GitHub macOS 회귀 검사/릴리스 빌드/서명 검증 통과: https://github.com/miumi44/MacLikeWindowStyle/actions/runs/39548861952 .

로그아웃/재부팅은 사용자의 작업을 중단시키므로 실행하지 않았다. 실제 다음 로그인에서 백그라운드 시작 여부는 아직 확인하지 않았다. 저장 정책 단위 검사는 실제 로그인 동작의 대체 증거가 아니다. 커버리지는 측정하지 않았다.
