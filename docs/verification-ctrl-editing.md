# Ctrl 편집 단축키 업데이트 검증

WindowBridge 0.2.1 (build 3), 2026-10-20.

- `scripts/test-windowbridge.sh` 통과: 기존 설정/복원·한영 보호·창 관리 회귀 검사 포함.
- 새 검사: 기존 Ctrl+C/V/A 정책의 mixed 표시, 왼쪽 Ctrl로 확장 후 on 표시, 독립 끄기/켜기, Shift 조합과 다른 단축키 보존, 장치 및 사용자 앱 경로 예외 보존, 배포 예제 확인.
- release 빌드 및 앱 서명 검증 통과. 설치된 앱과 배포 빌드의 바이너리 일치 확인.
- 실제 앱 UI에서 새 체크박스 선택 → 변경 적용 → 적용 성공 및 켜짐 표시 확인. 재실행 후 기존 Alt+Tab과 창 관리 활성화 확인.
- 적용 전후 로컬 설정 비교: unshifted A/C/V 조작자만 변경되고 나머지 JSON 데이터 보존.
- 실제 물리 키보드에서 Codex 입력칸의 왼쪽 Ctrl+A/C/V 전체 선택·복사·붙여넣기와 오른쪽 한영키 전환·한글 입력이 모두 정상임을 사용자가 확인함. IDE 통합 터미널의 오른쪽 Ctrl+C 실행 중단은 별도 실기 검증하지 않음.

전용 터미널·VM·원격 데스크톱의 기존 예외를 유지한다. 기존 사용자 예외 및 장치 범위도 유지하므로 모든 환경에서 일괄 적용한다고 보장하지 않는다. 테스트 커버리지는 측정하지 않았다.
